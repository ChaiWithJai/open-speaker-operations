# Synthetic demo headshots

These eleven portraits are fictional competition-demo fixtures generated with OpenAI's
built-in image generation tool on 2026-08-10. They do not represent the named demo
speakers or any known real person. Theo Martin intentionally has no image so the public
photo-less fallback remains visible and testable.

The source prompt requested exactly twelve distinct fictional adults in a consistent 4×3
studio contact sheet, with diverse age, skin tone, gender presentation, hair, and
professional style; equal square head-and-shoulders cells; natural editorial photography;
and no text, logos, watermarks, celebrity likenesses, or duplicated faces. Eleven cells
were cropped mechanically to 362×362 JPEG files. The twelfth generated face is unused.

These packaged files are used only when the event slug is `speakerops-demo` and the email
matches the deterministic fixture map in `pretalx_speakerops.demo_assets`. Normal events
continue to use native speaker-uploaded avatars.
